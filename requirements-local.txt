# Lean install for a laptop with little disk space.

# to the DagsHub/DVC remote, browse MLflow and run the registry gate. It
# deliberately leaves out torch, transformers and peft, which are the heavy
# packages: training and evaluation run on Colab, the API runs on EC2.

#   pip install -r requirements-local.txt
#

#
# Lower bounds rather than exact pins on the data stack, because pinning
# datasets and pyarrow to an exact old version makes pip try to build
# pyarrow from source on newer Pythons, which fails. Python 3.11 or 3.12 is
# the safest choice, but this resolves on 3.13 too.
